---

```bash
pnpm add -D @doubleloop-io/oxlint-plugin-effect oxlint
```

Requires Node `^22.20.0 || >=24.8.0` and oxlint `^1.82.0`. What a release may change and which oxlint versions are supported: [Versioning](versioning.md).

Then extend the `all` preset: see [Configuration](configuration.md).
